Boundaries

Non-negotiable. Say these on the first call.

  1. Thai-side data and Burmese diaspora only. No Myanmar-state contracts.
  2. No junta ministry partnerships without a written sanctions opinion.
  3. Burmese-script-first. English is a secondary toggle.
  4. Discovery, not diagnosis. The AI mentor reflects. It never labels.
  5. Real-human escalation for crisis. Self-harm, exploitation, trafficking, deportation fear.
  6. No PII collected by default across all five surfaces.
