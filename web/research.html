research briefing

Can this be built on open data?

สร้างระบบนี้จากข้อมูลเปิดได้ไหม

Yes — all five surfaces can be assembled from verified public feeds, with receipts.

ใช่ — ทุกพื้นผิวสร้างจาก feed ที่ตรวจสอบแล้ว

Method: corpus merge, verified RSS feeds, institutional-grade source-checking (ILO, depa, UNESCO Bangkok, ASEAN Skills). Data: last checked Sept 2026. Scope: five surfaces — Rooms, Digest, Listening, Atlas, Career Navigator.

วิธี: merge corpus, feed RSS ตรวจสอบ, แหล่งที่มารัฐบาล. ข้อมูล: ตรวจสอบ ก.ย. 2569. ขอบเขต: ห้าพื้นผิว — ห้องแชท, อาหาร กลื่ม, ฟัง, ตู้ภาพอาชีพ, นำทางอาชีพ

Method

Each surface ingests only verified open data. No HTML scraping. Source integrity checked at ingest time; stale feeds are retired. The table below maps surface × source.

What needs humans

Burmese NLP
Myanmar Unicode normalization, stanza-segmentation, and sentiment analysis require native-reviewer validation. No off-the-shelf model handles Burmese script fully.
การ Natural Language Processing ในภาษาบึ้งต้องการการตรวจสอบจากผู้รู้ถิ่นจริง ไม่มีโมเดล off-the-shelf ที่ครอบคลุมสคริปต์พม่าได้เต็มที่
Crisis escalation routing
Keyword triggers (self-harm, exploitation, trafficking, deportation fear) must route to real human hotlines. Model refusal is not a safety mechanism.
ตัวตั้งคำขั้น (self-harm, exploitation, trafficking, โจทย์ขับไล่) ต้องโหมดถึง hotline จริง ไม่ใช่การปฏิเสธของโมเดล
Data source integrity
Every RSS feed, GDELT query, and NASA API response must be spot-checked quarterly. Stale sources are retired, not silently carried.
ทุก Feed RSS, query GDELT และ response NASA API ต้องตรวจสอบทุก 3 เดือน แหล่งที่มายาวนานจะถูกเลิกใช้ ไม่ใช่ถูกซ่อนไว้
Verified placement outcomes
Atlas job/scholarship clicks must be matched with real placement data from partner organisations. Click-through is not the same as outcome.
การคลิก Atlas ต้องตรวจสอบกับข้อมูลการรับตัวจริงจากองค์กรพันธมิตร การคลิกไม่เหมือนผลลัพธ์

The verdict: all five surfaces are achievable from verified open data, provided human review stays in the loop for NLP, crisis routing, source integrity, and placement outcomes.

คำตัดสิน: ทุกพื้นผิวสามารถสร้างจากข้อมูลเปิดที่ตรวจสอบแล้ว ได้ โดยมีการทบทวนโดยมนุษย์ในขั้น NLP, การจัดการฉุกเฉิน, ความสมบูรณ์ของแหล่งที่มา, และผลลัพธ์การรับตัว
